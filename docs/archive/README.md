# Historical design and handoff archive

These files are retained for engineering provenance, regression archaeology and discontinued integration notes. They are **not supported setup instructions**, current security policy, or instructions for deploying the hosted service.

In particular, the `auth0_runtime/` and `auth0_tests/` directories describe retired authentication code and should not be copied into live deployments. Consult the root [README](../../README.md), [Architecture](../../ARCHITECTURE.md), and [Security](../../SECURITY.md) documents for current boundaries.
