# Milestone 9B1 — Hosted manuscript to local Schema 42 portability

**Editor 10.3.68 / Cloud 10.4.38.** Corrective M9B1 candidate, pending user-run Editor + Cloud verifier. Milestone 8 (M8A/M8B) and M9A were user-verified green together on Editor 10.3.66 + Cloud 10.4.38: Unit 89, Core/API 1150 (+1 skipped), browser 94, Durable E2E 92, Cloud 85.

## Two different package formats, two different purposes

1. **Hosted-v3 recovery archive** is still generated by `HostedProjectPackageService.export_bytes`. M9A snapshots continue to store exactly this archive in independent recovery storage. Its manifest is `breadmaker-hosted-project` v3, and it contains Firestore logical entities plus immutable authoritative assets, but no account authority. The hosted importer reads it into a **new hosted project** and grants new authority only via its new project-creation boundary. The v3 archive does **not** pretend to be accepted by the local importer.
2. **Local-portable v2 download** is generated by `export_local_bytes`, the default for hosted `GET /api/projects/{id}/export` and `GET /api/data/export`. The new `hosted.local_portability` codec turns a frozen authorized hosted-v3 snapshot into a **current local Schema 42** SQLite database in memory and a native `breadmaker-project` version-2 ZIP. It never uses that SQLite connection as live hosted persistence. The unchanged local `Workspace.verify_package` / `Workspace.import_project` validate and import it into an independently generated local project identity.

## Hard safeguards

- Firestore membership checks and a **pre/post project-generation fence** bound the entire hosted-to-local export. A concurrent write aborts rather than publishing mixed revisions.
- Conversion rejects unsupported logical entities or fields, malformed ZIP manifests, duplicate member names, missing/dangling foreign relationships, invalid digest assets, asset reference holes, invalid local SQLite constraints, oversized input and excessive uncompressed data. No unsupported author content is knowingly dropped to make a download appear successful.
- Local database foreign keys and quick check are validated before returning the ZIP. Every output entry except the manifest has a SHA-256 in `file_hashes`; local verification independently rechecks each entry and validates the project identity against the SQLite project row.
- Source hosted project IDs and collaborator identity cannot become local account credentials: the package contains content only and the local importer installs a **fresh** local project UID. No provider tokens, memberships, live GCS pointers or service secrets are exported.
- Hybrid manuscript body is hydrated from exact-generation immutable GCS before it is serialized; a missing or corrupt authoritative GCS object is a hard failure. The hosted-v3 recovery archive format and its own create-only/verified storage policy do not change.

## Deliberate B1 scope and remaining B2 work

This checkpoint is a *fail-closed bridge*, not a declaration of all-feature portability. It directly exercises a real hosted **Manuscript** export and the unmodified local importer, in addition to v3 hosted import into a new project. New hosted-only entities or complex local structures that cannot be translated exactly (including some Review snapshot/checkpoint and advanced Canvas/Map structures) are **rejected** rather than stripped. M9B2 must add fixture-backed equivalence tests for every complex structure and its authoritative asset references, and refine any mismatched shape before calling M9B complete.

The synchronous route is limited to 64 MiB of hosted-v3 package input/output and 192 MiB of inflated state; larger exports require an independently bounded Cloud Run Job/direct transfer in M9D/M10. No production cloud is deployed here, and no local schema, local runtime, verifier, watchdog or frozen M3/M4 adapter is modified.


## M9B1 corrective: portable timestamps and asset-version identity

The user-run 10.3.67 gate reported 29 Editor failures (26 were a single
unsynchronized Review logo CSS cache-buster, three were Schema-42 chapter
`created_at` failures); Cloud verification passed. The Review logo URL now uses
the same version as the Editor release and the other frontend assets.

Hosted-v3 recovery archives deliberately omit provider-owned entity timestamps
(`created_at`, `updated_at`), whereas local Schema 42 requires these columns.
The local-portability codec now fills **only absent** local timestamp columns
from the authoritative hosted project's created/updated timestamps supplied to
the conversion. These are *project-level fallback timestamps*, not recovered
entity-level historical timestamps. Explicit entity timestamps, when available,
are preserved. Any other required content/schema incompatibility remains a
fail-closed export error; the hosted-v3 archive is unchanged. M9B2 must evaluate
historical timestamp fidelity alongside Review/Canvas/Map/checkpoint parity.

No user suite was run by the model; 10.3.68 still requires full operator Editor
and Cloud verification before M9B1 can be closed.

## M9B2A: typed, non-FK Canvas/Map relationships (Editor 10.3.69 candidate)

This is **the first half of M9B2**, not a claim that all historical Review or
Canvas versions are locally restorable. M9B1's 10.3.68 corrective was carried
forward without a user-run gate; only the full next operator verifier can close
both pending checkpoints.

The M9B2A export codec explicitly translates links that local Schema 42 models
as strings rather than declared SQLite foreign keys:

- `map_items.start_anchor_id` and `end_anchor_id` with `chapter`/`scene` anchor
  types are rewritten to local integer IDs (stored as decimal text). Invalid,
  unknown, mismatched, or incomplete typed anchors fail the export.
- `map_items.source_key` for automatically populated `chapter:<id>` and
  `scene:<id>` entries is likewise rebased. Independent template keys remain
  exactly as authored, so subsequent local map population does not create
  false duplicate stops or lose the connection to the manuscript.
- `references_map.source_id`/`target_id` are rewritten when the declared type
  has a known local equivalent; opaque external/custom types remain text.
- Native developmental `canvas_version_items.entity_id` links can be rebased
  from chapter/scene ids. Live Canvas node/edge and Map line/item/junction
  records already use declared FKs, which the converter rebases in its main pass.

**Incompatible semantics are intentional hard errors.** Hosted Canvas versions
contain frozen node/edge geometry (`kind`, `source_id`, `payload`), whereas local
Canvas versions contain chapter/scene developmental placements. Hosted Review
snapshots contain a complete project-level JSON object rather than six local
snapshot relational projections. Hosted checkpoints have a structured snapshot
rather than the required local checkpoint byte codec. The converter now returns
three distinct errors in those cases instead of attempting to fake local
history: `HOSTED_PORTABLE_CANVAS_VERSION_SHAPE_UNSUPPORTED`,
`HOSTED_PORTABLE_REVIEW_SNAPSHOT_PROJECTION_REQUIRED`, and
`HOSTED_PORTABLE_CHECKPOINT_CODEC_REQUIRED`.

M9B2B remains responsible for **actual round-trip fidelity** of these historic
structures. A hosted project containing one must remain exportable in its
independent hosted-v3 recovery format; its local-v2 portable download will
fail explicitly until its corresponding codec is complete. M9C/M9D, bucket
policy, scheduled backups, infrastructure and live restore are still pending.

M9B2A adds operator-only conformance tests in `tests/test_v10369.py` that
exercise real local verification/import for graph links, rebased typed anchors,
source keys and relational equivalence; reject dangling typed anchors and
untranslatable historical shapes. Tests were **not run by the model**.

## M9B2B — restricted historical restoration (Editor 10.3.70)

See `HOSTED_PORTABILITY_M9B2B.md`. Read-only, single-round manuscript Reviews
with full frozen project snapshots now have an explicit local round projection
and a **derived** frozen Book checkpoint; native local-format v1 checkpoints
without historical annotation payload can also be converted with hash and
asset validation. Hosted/local Review IDs and main-Manuscript Tab roles are
reconciled. Richer hosted Canvas geometry histories, multi-round or advanced
Review semantics and project-shaped hosted checkpoints still fail closed.
**M9B remains partially complete, not fully lossless for all hosted content.**
